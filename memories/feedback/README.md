# 用户反馈与行为模式

## UI/UX 设计原则

### 1. 前端校验前移
**反馈**: 非法选项要在前端就置灰/不展示  
**应用**: 校验前移到选择那一刻, 别等提交才报错  
**示例**: 相册上传未选分组时置灰提交按钮

### 2. 弹窗/表单无解释性文案
**反馈**: 弹窗/表单里不要加解释性说明文案  
**应用**: 用结构差异代替灰字解释, 报错文案除外  
**示例**: 密码本新建弹窗只有字段本身, 没有"这是什么"的说明

### 3. 弹窗标题只放固定名词
**反馈**: 弹窗标题只放固定名词, 元信息放正文  
**应用**: traceId/请求接口走正文灰字行, 协议 Tag 排在文字前面

### 4. 复用平台通用样式
**反馈**: 新增 UI 要复用一站式平台通用样式  
**应用**: 弹窗内表格也要一致; Modal 在 body portal 里, 得靠 wrapClassName 才吃到 extend

### 5. Toggle 放在状态列
**反馈**: 可切换状态就放在"状态"列, 开关用默认尺寸  
**应用**: 别在操作栏再放一个; small 开关塞中文会被挤扁

## 开发行为规范

### 6. 最小实现 + 与现有口径一致
**反馈**: 方案设计要「与现有口径一致 + 最小实现」  
**应用**: 别主动加白名单/可配置项/特例流程, 用户会逐条砍掉

### 7. 删除概念要删到库里
**反馈**: 说"删除某概念"就要删到库里  
**应用**: 表/后端/两端 UI/文档一起抹掉, 别只砍 UI、别因"通用能力"留壳

### 8. 编辑钉钉文档前先读回最新内容
**反馈**: 编辑钉钉文档前先读回最新内容  
**应用**: 用户会手改文档, 改前先 read_doc, 优先追加/块级编辑而非整篇覆盖

### 9. 环境问题优先改我这侧
**反馈**: 环境问题优先改我这侧, 别让用户动 IntelliJ 配置  
**应用**: 端口/启动参数冲突宁可我重启 5 分钟, 也不让用户翻 Run Configuration

### 10. 每次代码修改后必须用浏览器实际测试
**反馈**: 每次代码修改后必须用浏览器实际测试  
**应用**: 不能仅靠 curl 验证后端接口

## React/Antd 技术要点

### 11. 避免 && 渲染数字类型布尔字段
**反馈**: React 中避免用 && 渲染数字类型的布尔字段, 防止 0 被直接显示  
**应用**: 后端 Integer 型布尔值需显式比较, 不可依赖 falsy/truthy  
**正确做法**: `{count > 0 && <span>{count}</span>}`

### 12. 可选链访问嵌套数组前需完整空值检查
**反馈**: React 可选链访问嵌套数组前需完整空值检查  
**应用**: `data?.list.map()` 会返回 undefined, 需用 `data?.list && data.list.map()`

### 13. antd Menu 需用受控 openKeys
**反馈**: antd Menu 需用受控 openKeys 保持展开  
**应用**: 避免路由变化时自动收起  
**配合**: 需配合 onOpenChange 回调, 否则点击一级菜单无响应

### 14. antd v6 Form.List 在共用 FormModal 里回填不上初值
**反馈**: antd v6 Form.List 在共用 FormModal 里回填不上初值  
**应用**: 弹窗内动态行改用组件 useState, 别去改外壳

### 15. antd v6 Select 脚本操作 DOM 要点
**反馈**: antd v6 Select 无 .ant-select-selector  
**应用**: 对 .ant-select-content 派发事件开下拉

## 数据库规范

### 16. 所有表必须同时有创建时间和更新时间
**反馈**: 所有表必须同时有创建时间和更新时间  
**应用**: 关联表/明细表/快照表也不算例外, 缺了就用新迁移补

### 17. Flyway 迁移版本号必须唯一
**反馈**: Flyway 迁移版本号必须唯一  
**应用**: 重复版本导致启动失败

### 18. Flyway 迁移字段冲突
**反馈**: 重命名表后避免重复添加已存在字段  
**应用**: V303 重命名后 ADD COLUMN 需检查 V302 是否已添加

### 19. 服务端禁用 @TableField(fill=...)
**反馈**: 没注册 MetaObjectHandler, MP 会把该列写 NULL 撞 NOT NULL  
**应用**: 新城市必 500, 改用手动 set

## 验收与测试

### 20. 验收时别用 class 直接抓弹窗/气泡确认框
**反馈**: 隐藏标签页离开动画不结束, 残留实例会导致误点误删  
**应用**: 用 data-testid 或更稳定的选择器

### 21. 远端分支存在性用 git ls-remote 判断
**反馈**: git branch -a 只反映本地 refs, 据此误判会凭空新建同名分支  
**应用**: `git ls-remote origin | grep <branch>`

**命令**: `pnpm dev:admin` (B端), `pnpm dev:h5` (C端)
